# 引脚分配表

| 引脚 | 功能 | 说明 |
|------|------|------|
| PA9  | UART_TX | 调试串口发送 |
| PA10 | UART_RX | 调试串口接收 |
| PA5  | SPI_SCK | SPI时钟 |
| PA6  | SPI_MISO | SPI主入从出 |
| PA7  | SPI_MOSI | SPI主出从入 |
| PA4  | SPI_CS | SPI片选 |
| PB6  | I2C_SCL | I2C时钟 |
| PB7  | I2C_SDA | I2C数据 |
| PC13 | LED_STATUS | 状态指示灯 |
| PA0  | BTN_USER | 用户按键 |

> 此文件应与原理图保持同步。每次硬件改版需更新。
