# TPS61023 升压电路工程修改记录

已围绕 POWER 页现有 U4 绘制，保留 U4 位置。输出约5.2V供 ISL55110 VH；VDD继续使用3.3V。

| 位号 | 参数 | 工程本地封装 |
|---|---|---|
| C72 | 10uF / 10V | C_0603_1608Metric |
| C73 | 100nF | C_0402_1005Metric |
| C74 | 22uF / 10V | C_0805_2012Metric |
| C75 | 22uF / 10V | C_0805_2012Metric |
| L2 | 1uH / DFE201610P | L_Murata_DFE201610P |
| R49 | 1K | R_0402_1005Metric |
| R50 | 10K | R_0402_1005Metric |
| R51 | 77.4K 0.1% | R_0402_1005Metric |
| R52 | 10K 0.1% | R_0402_1005Metric |
| U4 | TPS61023DRLR | TPS61023DRLR |

- PB0 / STM32G431CBU6 17脚 → BOOST_EN → R49 1K → U4 EN。R50 10K在EN侧下拉；固件尚未修改，需要初始化输出低并在3.3V稳定后使能。
- R51=77.4K、R52=10K均0.1%，PWM典型VOUT=0.595*(1+77.4/10)=5.2003V。考虑基准与电阻极限约5.060～5.341V，未包括纹波和瞬态。
- L2采购型号 DFE201610P-1R0M=P2，2.0×1.6×1.0mm，电感下降电流标称3.1A、温升电流2.2A（按厂家条件）。采用小电感的前提是本支路目标200mA；不是把TPS61023的开关电流当作输出额定电流。启动、过载、温升需样板验证。
- C72 10uF/10V用0603，采购须保证3.3V偏压下有效容量至少4.7uF。C74/C75各22uF/10V用0805，5.2V下合计有效至少10uF；不能仅按标称容量选料。
- R49～R52、C73使用0402；未用0201，避免反馈精密阻值采购与装配限制。U4原SOT563封装保持。
- 新电感的符号、封装、STEP模型均迁入项目库；全部新增元件的模型引用已验证为KIPRJMOD本地路径。
- 在EXT页移除VH原+5V电源符号，改为+5V2_DRV，保留C48/C49本地去耦。
- EN关闭不主动放空VH电容；固件需配置合适BOR，验证快速断电重启时序。200mA输出约需3.3V侧350mA（90%效率估算），需核算3.3V稳压器散热。

## 验证

ERC由8项变为2项，新增电路没有新增ERC问题；剩余为原有主图悬空短线和U15 PC4（16脚）未连接。未擅自连接PC4。
已检查POWER、MCU、EXT图面；导出网表确认VIN、SW、FB、GND、输出、GPIO串阻及下拉连接正确。
PCB未更新；此为原理图和库资产修改，不代表固件或硬件验证已完成。
