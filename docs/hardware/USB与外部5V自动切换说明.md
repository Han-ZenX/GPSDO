# USB 与外部 5 V 自动切换

已修改 POWER.kicad_sch，USB 可为整机供电，CN1 外部 5 V 优先。

| 器件/网络 | 接法 |
| --- | --- |
| CN1 → F1 → EXT_5V | 接 U18 VIN1（3 脚）及 MODE（5 脚），作为优先输入 |
| USB1 VBUS | 接 U18 VIN2（6 脚），作为备用输入 |
| U18 TPS2116DRLR | 2、7 脚共同接整机 +5V；1 脚接 GND；8 脚 ST 不使用并标记不连接 |
| R43 / R44 | 30.1 kΩ / 10 kΩ，均 1%、0402；EXT_5V → R43 → PR1（4 脚）→ R44 → GND |
| C68 / C69 | 两路输入各 1 µF / 16 V，0603，X7R；选型保证 5 V 偏压下有效电容至少 1 µF |
| C70 / C71 | 输出 100 nF / 16 V（0402）+ 22 µF / 10 V（0805）；C71 在 5 V 下有效电容至少 10 µF |
| C26 / C46 | 原有输出 10 µF / 100 nF 去耦保留 |
| R45 | 新增 1 kΩ、0402，给原直接跨电源连接的 D8 限流 |

两路同时存在且外部电源有效时优先使用 CN1；外部电源消失或低于 PR1 门限时切到 USB。芯片提供反向电流阻断，两路电源没有直接短接，不作并联均流。PR1 的典型切换点为 1 V × (1 + 30.1k/10k) = 4.01 V；芯片基准公差为 ±8%，加上电阻公差，不能把它当作精密欠压保护。

两路均只允许稳压 5 V，输入不得超过 5.5 V。TPS2116 是电源选择开关，不稳压，也不提供负载过流限流；负载不得超过其 2.5 A 能力，并需依据铜面积、温升、线路和上游电源保护设计实际工作电流。原 F1 是 3 A 保险丝，不能据此认为已经为 2.5 A 开关提供了精密过流保护。

USB 供电器及线缆需能承担 OCXO 冷启动预热和整机峰值电流。现有 CC1/CC2 的 5.1 kΩ 下拉只表明受电端身份，没有实现 Rp 电流档位检测或 USB PD 协商；接普通电脑 USB 口不能默认获得大电流，当前接法不等于完成 USB 取电合规设计。若需要兼容任意电脑 USB 口，应另外加入电流能力检测、限流与必要的负载管理。

PCB 上 C68/C69 应分别靠近 VIN1/VIN2，C70 靠近 VOUT，C71 靠近输出供电节点；2、7 脚都必须接铜。两路输入、输出及地采用短而宽的走线。实际切换存在短暂断开，不能保证时钟不断电；样机需在最大负载下测量切换跌落、冷启动电流、插拔尖峰及芯片温升。

U18 符号、SOT-583-8 封装及 STEP 模型已迁入项目本地库，模型使用 ${KIPRJMOD} 相对路径。未修改 PCB 布局。

验证：KiCad 网表确认输入隔离、输出 2/7 脚及分压连接正确；ERC 无新增条目，修改前 85 条、修改后 83 条。项目其余原有问题未在本次处理中修复。此前已移除 -5 V 发生器，但 EXT 页 U4/U12 仍为 BUF602，单电源输出级仍需继续修改。
