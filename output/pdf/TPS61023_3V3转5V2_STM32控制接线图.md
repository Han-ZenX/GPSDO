# TPS61023 3.3V 转 5.2V 接线说明

此为矢量接线设计图，未修改 KiCad；位号为示例。保留 ISL55110，STM32 控制升压 EN。

- 官方引脚：1 FB，2 EN，3 VIN，4 GND，5 SW，6 VOUT。1uH 电感接 3.3V 与 SW 之间。
- R3=77.4k、R4=10.0k，均0.1%；Vout=0.595*(1+77.4/10)=5.2003V。
- 仅计 PWM 基准0.580～0.610V和电阻独立0.1%极限：输出约5.060～5.341V；未计纹波、负载瞬态、走线压降。PFM需另测。不能把5.2V作为精确恒定值。
- 暂按200mA负载规划：效率90%时输入约350mA；既有3.3V LDO损耗额外约(5-3.3)*0.35=0.595W。需核算既有负载与温升。
- L1初选屏蔽1uH、Isat>=5A、Irms>=1.5A，不等于限定输出电流；启动和保护状态需复核。
- C1=10uF/10V，0805；C3/C4各22uF/10V，0805或1206；按具体料号的DC偏压曲线核实有效容量。
- EN串1k、对地10k，普通空闲GPIO推挽控制。GPIO编号尚未分配，不能声称固件已实现。
- MCU启动后延时20ms只是设计初值，不是ISL55110规定间隔。上电时先VDD后VH；可等VH实测稳定后开始输出。
- 输出没有主动放电：若需可预测重启，预留额外放电电阻/受控放电电路，并结合BOR、复位时序及输出电容实测决定。
- 取地使用连续地平面，不割裂回流。输入与输出去耦靠近芯片，特别缩小VOUT/输出电容/GND高频回路。
- 实测至少覆盖冷启动、快速重启、双电源切换、负载阶跃，以及VH最低值/过冲/纹波。
